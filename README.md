# 🧮 VAT Calculator Web Application

A lightweight, fast, and user-friendly Value Added Tax (VAT) calculator web tool designed to help individuals, freelancers, and businesses quickly compute tax amounts, inclusive prices, and exclusive prices. 

🔗 **Live Tool:** [VAT Calculator](https://vatcalculater.com/)

---

## ✨ Features

* **Instant Calculation:** Instantly compute VAT add-ons and deductions as you type.
* **Flexible Modes:** Easily switch between adding VAT (Exclusive to Inclusive) and removing VAT (Inclusive to Exclusive).
* **Custom Tax Rates:** Enter standard, reduced, or custom VAT percentages based on your region.
* **Responsive Design:** Optimized for seamless usage across desktop, tablet, and mobile devices.
* **Clean UI:** Minimalist interface focused on speed and ease of use.

---

## 🚀 Built With

* **HTML5 / CSS3** – For a clean, modern, and accessible interface.
* **JavaScript (ES6+)** – For real-time, client-side calculations without page reloads.
